index.html 캐시로 /api가 HTML로 남는 현상 방지
CDN이 index.html을 강 캐시하면, 잘못된 HTML이 /api 경로까지 섞일 수 있어요. index.html만 no-store로 내려줍니다.

applypatch << 'PATCH'
*** Begin Patch
*** Update File: server/index.ts
@@
-const clientDist = path.join(process.cwd(), "client", "dist");
-app.use(express.static(clientDist, { fallthrough: true, maxAge: "1h" }));
-app.get("*", (_req, res) => {
-  res.sendFile(path.join(clientDist, "index.html"));
-});
+const clientDist = path.join(process.cwd(), "client", "dist");
+app.use(express.static(clientDist, { fallthrough: true, maxAge: "1h" }));
+app.get("*", (_req, res) => {
+  res.setHeader("Cache-Control", "no-store"); // 🔒 HTML 캐시 방지
+  res.sendFile(path.join(clientDist, "index.html"));
+});
*** End Patch
PATCH

B안: 프론트와 API 도메인 분리 (대안)

지금 레플릿은 **프론트 전용(Static)**으로 두고,

새 Repl을 만들어 서버 전용으로 띄운 뒤(서버 Repl의 도메인 예: api-yourapp.username.repl.co)

클라이언트의 업로드/헬스체크/블로그 API 베이스 URL을 https://api-yourapp... 로 지정

프론트 .env 예:

VITE_API_BASE=https://api-yourapp.username.repl.co


관리자 업로더에서:

const base = import.meta.env.VITE_API_BASE ?? "";
await fetch(`${base}/api/upload/image`, { ... });
